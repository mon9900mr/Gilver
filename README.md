# GILVER — Gold & Silver Atelier

A Persian, responsive, multi-page jewelry gallery storefront built with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — editorial landing page
- `gold.html` — gold catalog with category filters and sorting
- `silver.html` — silver catalog with category filters and sorting
- `product.html` — product detail page (`?id=g01`)
- `wishlist.html` — saved products
- `cart.html` — shopping bag
- `about.html` — brand story
- `contact.html` — contact form UI

## Stack
- HTML5, CSS3, vanilla JavaScript
- Responsive layouts and mobile navigation
- LocalStorage for demo cart and wishlist
- IntersectionObserver reveal animations

## Run
Open `index.html` in a browser, or enable GitHub Pages in repository Settings → Pages and deploy from the `main` branch / root folder.

## Important before launch
Product catalog entries, prices, availability, and contact details are demonstration content. Replace them with verified gallery information. Cart, newsletter, and contact form currently run client-side only; connect a secure backend/payment provider before accepting real orders. Product imagery and Google Fonts load from external services.
